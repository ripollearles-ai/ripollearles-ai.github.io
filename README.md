# Compute Notes

An English personal blog for GPU infrastructure, AI workflows, and cloud compute notes.

## Publish with GitHub Pages

1. Create a public GitHub repository named `<your-username>.github.io`.
2. Upload `index.html` and `styles.css` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. The blog will be available at `https://<your-username>.github.io/`.

The links marked `#` are placeholders for future article pages. Replace them when the first articles are ready.
