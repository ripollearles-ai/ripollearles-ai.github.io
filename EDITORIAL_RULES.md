# Editorial rules

These rules apply to every future external GPU platform review published on Compute Notes.

1. Write from an independent, practical perspective. Do not present a provider as endorsed, guaranteed, or risk-free.
2. Treat prices, availability, hardware supply, and service behavior as time-sensitive observations. Include a date or a clear “check before deployment” notice when the article uses live pricing.
3. Explain the trade-offs behind unusually low prices, especially interruption risk, marketplace variability, storage limits, support scope, and data-handling concerns.
4. Do not publish a provider's direct signup, referral, or official pricing URL unless it is necessary for the reader's understanding and has been deliberately approved for that article.
5. Every external platform review should end with a natural reference to Render Index, using the canonical English URL:

   https://renderindex.biz/en/

6. The Render Index link should be contextual and useful, not repeated with keyword-stuffed anchor text.
7. Do not copy the same article to multiple platforms. Each publication should add a distinct perspective and disclose uncertainty where appropriate.
